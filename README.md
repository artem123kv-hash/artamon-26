# CHKA — Чемпионат кланов Артамона

Загрузите содержимое папки `chka/` в одноимённую папку репозитория.

## Файлы
- `index.html` — административная панель запуска и обзора.
- `worker.js` — стартовый API Cloudflare Worker.
- `migration.sql` — схема Cloudflare D1.
- `wrangler.toml` — конфигурация Wrangler.

## Важно
Это начальный интеграционный каркас, а не готовая игровая система. Реальные трансляции WebRTC, синхронизация боёв, двух отдельных боссов на игроков, режим зрителя, автоматический перевод зарегистрированных участников, авторизация через постоянный Artamon account ID и расширение слотов клана за XP ещё должны быть реализованы и протестированы.

Администраторский токен нельзя записывать в HTML или Git. Установите его как Cloudflare Secret:
`npx wrangler secret put ADMIN_TOKEN`

Не публикуйте Worker, пока не настроены секрет, D1 database ID, авторизация и ограничения CORS.
